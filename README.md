# 📊 Superstore APAC Interactive Dashboard (Tableau)

## 🔍 Project Overview
Built an interactive Tableau dashboard to analyze **Sales, Profit, and Quantity** across the **APAC region**, enabling dynamic KPI selection and state-level drill-downs for granular performance insights.

The dashboard helps identify:
- Top-performing categories and sub-categories  
- Loss-making sub-categories  
- Most profitable shipping modes  
- State-level performance variations  

## 🧠 Key Features
- Dynamic KPI selection (Sales, Profit, Quantity)
- State-level filtering and drill-down analysis
- Trend analysis for Sales, Profit, and Quantity
- Category, sub-category, segment, and ship mode profitability insights
